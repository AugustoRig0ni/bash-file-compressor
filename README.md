# Linux File Compressor

Script em Bash para compactar e descompactar arquivos utilizando `.tar.gz`.

## Funcionalidades

* Compactação de arquivos
* Descompactação de arquivos
* Verificação de existência do arquivo informado
* Criação automática de diretórios de destino
* Exibição do tamanho do arquivo compactado
* Interface simples via terminal

## O que aprendi neste projeto

Durante a evolução deste script, pratiquei conceitos importantes de Linux e Shell Script:

* Estruturas condicionais (`if`)
* Estruturas de seleção (`case`)
* Manipulação de variáveis
* Criação automática de diretórios com `mkdir -p`
* Compactação e extração com `tar`
* Tratamento básico de erros
* Permissões de execução (`chmod +x`)
* Uso do Git e GitHub via SSH

Além disso, estou utilizando Linux em dual boot e buscando aplicar os conceitos estudados na prática através de pequenos projetos e automações.

## Como executar

```bash
chmod +x compedescomp.sh
./compedescomp.sh
```
